# Materiales originales de las casillas

Las siguientes imágenes se generaron con ImageGen para Crónicas del Nexo el
29 de octubre de 2026. El juego usa las versiones WebP optimizadas de 1024 ×
1024 en `public/assets/terrain/`; los maestros PNG y el registro de revisión
se conservan localmente en `tools/art-inbox/board/`, carpeta ignorada por Git.

de sus escenarios; no se usó arte de terceros.
